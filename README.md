Solmar Bay is an original 3D open-world crime game that plays offline in a desktop browser: explore a sun-soaked coastal city on foot and by car, steal cars, outrun the police across a 0–5 star wanted level, and run 7 story jobs for fixer Mama Rosa. Built by an AI agent for make.fun's "Make the best game" bounty.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
